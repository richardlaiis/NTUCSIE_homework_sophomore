\subsection{}
Although preemptive fixed-priority scheduling is often disadvantageous to the lowest-priority task because higher-priority tasks can interrupt it multiple times, in this case $\tau_2$ still has a smaller worst-case response time than $\mu_2$.

The key reason is that non-preemptive CAN analysis includes an additional blocking term $B_2$:
\[
Q_2 = B_2 + \sum_{j:P_j<P_2}\left\lceil \frac{Q_2+\tau}{T_j} \right\rceil C_j,
\qquad
R_{\mu_2}=Q_2+C_2.
\]
In contrast, preemptive fixed-priority analysis does not have this blocking term:
\[
R_{\tau_2}=C_2+\sum_{j:P_j<P_2}\left\lceil \frac{R_{\tau_2}}{T_j} \right\rceil C_j.
\]

From the computed results, $R_{\mu_2}=90$ msec while $R_{\tau_2}=70$ msec. Therefore, for this task set, the reduction from removing non-preemptive blocking is larger than the extra delay caused by preemptions, so $\tau_2$ ends up with a smaller worst-case response time.

\subsection{}
Choose the smallest feasible big-$M$ as
\[
M=2026.
\]

To guarantee
\[
\alpha x = y \iff 0\le y\le x \;\wedge\; x-M(1-\alpha)\le y \;\wedge\; y\le M\alpha,
\]
we analyze both values of $\alpha$. (Also the relationship given by the problem is trivially bidirectional.)

If $\alpha=0$, then the RHS becomes
\[
0\le y\le x\land x-M\le y\land y\le 0.
\]
From $0\le y$ and $y\le 0$, we get $y=0$, matching the LHS ($\alpha x = y \Rightarrow 0=y$).
For feasibility, we also need $x-M\le 0$ for all valid $x$, i.e., $M\ge x$. Since $x\le 2026$, this requires $M\ge 2026$.

If $\alpha=1$, then the RHS becomes
\[
0\le y\le x\land x\le y\land y\le M.
\]
From $y\le x$ and $x\le y$, we get $y=x$, matching the LHS ($\alpha x = y \Rightarrow x=y$).
To avoid excluding valid $x$, we need $x\le M$ for all $x\le 2026$, so again $M\ge 2026$.

Therefore, any $M\ge 2026$ works, and the tightest choice is
\[
\boxed{M=2026}.
\]
